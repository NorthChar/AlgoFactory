# ADR-001：选择银行咨询分类作为主案例

状态：已采用。

原题允许选择一个具体行业场景，要求至少一个完整算法生成与验证示例。选择 BANKING77 是因为它有公开文本、77 类标签、固定训练/测试划分和明确许可，适合展示自然语言需求、代码生成、分类训练、独立评分及错误修复。数据规模 13,083 条，轻量 CPU 分类器便于本地复现。

当前任务范围见 [分类目标](../intent-goals.md)，数据与许可见 [数据说明](../../data/README.md)。客户流失二分类和合成回归保留为公共框架的兼容检查，不声称真实业务效果或完整新场景产品。

详细开发讨论和初次选择过程保存在 [历史决策](https://github.com/NorthChar/AlgoFactory/blob/2758572d4167b9f66420b79ffd415f51819cb60e/docs/decisions/0001-banking77-main-case.md)。
