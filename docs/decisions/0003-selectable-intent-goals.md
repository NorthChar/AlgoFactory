# ADR-003：将已有咨询数据开放为三个开发目标

- 日期：2026-11-02。
- 范围：实现全部意图分类、指定已有类别分类和单个意图识别，不立即引入其他银行业务数据。
- 状态：已实现并完成限定样例验证，纳入 0.8.0。
- 承接 ADR-001；原始题目与 docs/source 不变，历史全量任务证据保留。

原先仅改变算法及参数，不能满足用户对不同分类目标的需求。新增 goal / intents / objective 将需求真实绑定到数据筛选、标签映射、任务契约、生成约束、训练、评分、报告、回写和模型试用。沿用 BANKING77 的英文文本与现有人工标签，不把它当作交易记录或贷款数据。

指定类别仅在所选范围内适用；单个意图的负类为其他76个已知意图，不能声称实现未知意图检测。用户可优先减少漏判，系统采用可审查的类别平衡策略并改变候选排序，同时披露误报。此改动复用现有闭环，扩展为文本二分类和可选择的文本多分类；没有交付任意银行算法。

保留原始划分归属与行ID，分别冻结标签映射和验证协议；旧经验复用在派生目标中暂时禁用，避免将77类性能结论直接迁移。代码骨架可能相同，模型、数据与评估含义按确认的目标变化。

验收包括307项完整回归（含真实Docker）、四个工作台目标样例及隔离试用、派生目标最终测试。另用8次真实API请求完成一次语义拒绝记录、修正说明后的需求复核与单候选生成验证回写；没有超预算继续调用。详细范围见[证据摘要](../evidence/2026-11-02-intent-goals.json)和[操作与实现说明](../intent-goals.md)。这不代表所有类别组合或所有自然表述都已验证。
