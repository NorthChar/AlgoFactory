## 7A：数据与验证错误浏览

- 首页以实际导入结果展示原始 13,083 条、清洗后 13,072 条；训练 7,993、验证 1,999、测试 3,080 条。用“学习 / 比较与改进 / 最终评估”说明用途，保留清洗原因、来源、许可及版本。
- 默认浏览训练集，可切换验证集；展示英文原文、类别英文名称和可选人工维护的中文解释。中文解释只用于界面，不改类别 ID 或训练标签；不要把机器生成翻译伪装成原始标注。
- 不默认展示官方测试集逐条文本/标签或测试错误分析。浏览和筛选不改变数据指纹、划分、冻结协议或测试预约。
- 错误查看只读取已有验证集预测，绑定同一任务、数据、代码与划分；按 row_id 对齐真实标签和预测。没有相应文件或只有压缩归档时须明确处理，不通过重新预测伪造原次证据。
- 优先复用 datasets、现有验证产物和 web 的只读路径机制；新增受限读取接口，不让页面接受任意文件路径。

## 7B：可信模型与预测体验

- 明确三个对象：生成的 Python 代码、训练后的模型、验证报告。模型产物记录训练数据/划分、代码、参数、依赖版本、类别顺序及各自产物散列。
- 新运行在隔离容器内准备并保存可追溯的模型。具体序列化方式在实施时确定，先验证依赖兼容性与安全边界；不允许任意上传 pickle/joblib 或宿主不受信任反序列化。
- 历史记录没有模型时显示“尚未准备模型”。用户显式触发后，只按已核验代码和对应冻结训练集重新拟合，产物另存并标注为新准备，不冒充历史训练模型；不使用验证/测试数据拟合。
- 输入限制为非空英文文本并限制长度；呈现前三类及概率、模型版本和来源。概率不是正确率保证；没有未知意图检测时不得宣称能可靠识别领域外输入。
- 预测不调用 LLM，不触发代码修复、重排名或最终测试，不将单条人工输入的结果当成评估指标。对冻结测试文本的重复输入，应识别并拒绝体验预测，防止通过自由输入绕过标准测试入口。
- 模型缺失、散列/环境/标签错配、超时、无有效概率均清楚报错；不静默改用另一版本或重新训练。

## 7C：让配置真正影响实验

- 首轮仍使用 BANKING77 的 text/intent 协议、77 类及固定数据划分。用户可选择 Logistic Regression、MultinomialNB 或两者比较；参数只开放有限、可审查的取值，具体范围在实现前写入配置协议。
- 参数改变必须进入配置散列、模型提示、生成代码检查、容器执行、报告和知识回写；不能绕过现有固定参数检查，也不能仅替换 UI 标签。
- 保留原默认方案作为兼容基线。区分单候选实验和双候选比较，不把一个候选显示为“比较获胜”。配置或协议不一致的运行不直接混合排名。
- 需求描述与显式配置冲突时先提示并拒绝，不能静默忽略用户条件或声称理解了尚未支持的业务。任意自然语言自动选择全部超参数不在首轮范围内。
- 修复策略和参数候选在实验前冻结；结果展示以验证集为主，官方测试仅通过既有选定版本一次性入口访问。已知历史测试成绩不用于决定新参数。
- 继续严格执行每任务请求数及资源上限。先用 Mock 验证真实配置流和隔离执行；真实 API 补验收需另列小规模调用计划，不在此次计划整理中调用。

## Git、文档与验收规则

每个子阶段至少分开记录实现、测试与文档更新；优先复用现有架构，不复制另一套训练或评分逻辑。提交前检查变更范围、凭据和文档链接；提交后按现有私有远端同步，保留清楚的提交说明。

## 已冻结的实现选择

- 实验配置：`ExperimentConfig`，算法为 Logistic Regression / MultinomialNB / 两者，词组上限 1 或 2，词表上限 10,000 或 30,000，C 为 1.0 或 4.0，alpha 为 0.1 或 0.5。NB 指标优化按初值、1/2、1/10 顺序执行，修复预算仍生效；LR 没有额外搜索空间。
- 配置实验使用固定 BANKING77 业务描述；CLI 的额外自然语言要求在构造 Provider 前拒绝。旧入口继续保留原 API 需求解析；不声称能理解任意参数冲突。
- `experiment_hash` 标识算法/参数/预定优化规则；原 `config_hash` 继续标识评分协议，便于同一实验内部比较。配置贯穿提示、静态检查、执行元数据、报告、最终版本选择记录及知识来源。
- 模型以 gzip 压缩的 pickle 保存，仅来自受限代码在批准容器内的拟合，不接受上传。宿主只检查字节散列，反序列化始终在无网络、只读、非 root 容器中。模型绑定训练文件、代码、数据/划分、实验、类别及精确依赖环境。
- 预测限定 1–1000 个 ASCII 字符且至少含英文字母；这是输入格式限制，并不保证语义为英文。冻结测试文本按导入时的规范化规则匹配并拒绝；守卫读取测试特征，不读取测试标签或将其挂载给模型。
- 新训练在验证时保存模型；旧归档重新准备使用训练集拟合。环境变化或模型损坏后可显式重新准备，旧产物保留。模型文件只保存在本地 runtime；Git 归档保留元数据与散列，可通过源码和数据重新训练。
- 配置实验可引用适用的旧文本适配经验，但暂不允许在自定义参数下自动提炼新经验或恢复旧失败；CLI 在付费前拒绝这些组合，原默认流程仍支持。每次结果本身照常回写。
- 此次不新增付费 API 请求。配置提示传输和拒绝边界通过程序测试；新版配置真实 API 效果未复测，原 API 端到端证据仍是 Phase 3/4 的历史范围。
