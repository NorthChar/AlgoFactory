# AlgoFactory 工作台使用指南

工作台帮助你生成和验证分类算法。现在可以看样本、配置实验、检查错误并试用已生成的算法；训练数据仍使用预先导入的 BANKING77，不能上传任意业务数据。

## 第一次操作

1. 打开本机工作台 `http://127.0.0.1:8501/`，进入“了解数据”。训练集 7,993 条用于学习，验证集 1,999 条用于比较和修复，冻结测试集 3,080 条只用于最终评估。筛选一个英文类别，看看真实咨询怎样标注。
2. 进入“新建任务”，保留 BANKING77 和 Mock。Mock 不调用付费 API，但代码训练和评分真实执行。
3. 打开“自主选择算法与参数”。第一次可以只选逻辑回归，保留 C=4.0、单词+相邻双词、词表上限 30,000。参数含义可查看控件说明。不是参数越大就一定越好。
4. 保留“仅验证集评估”，修复次数可以设为 1，请求上限保留默认。点击“开始验证”。新任务只提交一次，刷新不会重复提交。
5. 等待“验证集通过”，进入“运行与报告”选择当前任务。先看成绩和下载代码，再展开“查看验证集中分错的咨询”，核对真实意图与预测意图。失败的候选也保留原始证据。
6. 进入“试用算法”，选择刚才任务的通过版本，输入一句自己编写的英文银行咨询，点击“预测这条咨询”。模型返回前三个已知意图及概率。概率不是正确率保证；单条预测不算标准评估。
7. 在“知识与来源”选择本地任务，追踪算法实现、验证、失败记录与文档来源；“运行与报告”的七步过程与题目要求 a–g 对应。

历史 API 案例只读浏览不收费。如果历史版本没有保存训练模型，页面会提示先“准备此版本模型”：这是按旧代码重新训练的新模型，使用训练集，不冒充历史权重。

## 参数选择与实验边界

| 可选项 | 支持范围 | 实际影响 |
| --- | --- | --- |
| 算法 | 逻辑回归、朴素贝叶斯、两者 | 单候选实验或同配置的双候选比较 |
| 文本特征 | 单词；单词和相邻双词 | TF-IDF 的 ngram_range |
| 词表上限 | 10,000；30,000 | TF-IDF max_features |
| 逻辑回归 C | 1.0；4.0 | 正则化强度，越小越强 |
| NB 平滑系数 | 0.1；0.5 | MultinomialNB alpha |
| 修复次数 | 每候选 0–2 次 | 接口错误修复与预定 NB 优化预算 |

NB 若因验证指标不足进入优化，alpha 最多按初始值、初始值的 1/2、初始值的 1/10 尝试。这个规则在提交前固定。选择单一算法不代表该算法“比较获胜”。每次实验显示配置编号，不把不同实验直接合并排名。

配置实验的业务描述固定，参数通过控件设置。CLI 也会拒绝配置实验中的额外自由文本要求，避免忽略冲突或先产生费用。旧的 API 需求解析入口保留原范围。

## 使用 CLI 复现

在项目根目录、已安装依赖、导入数据并批准镜像后：

```bash
.venv/bin/python -m algofactory.cli demo --task banking77 --mode mock \
  --experiment configs/experiment-baseline.json \
  --validation-only --max-repairs 1 --llm-call-budget 12 \
  --output-dir runtime/my-experiment --db runtime/my-experiment.sqlite
```

输出目录必须是新的。另一套已冻结的示例配置为 `configs/experiment-unigram.json`。这两套配置用于验证配置流确实生效，不表示后者优于默认值。

完整增量操作验收：

```bash
.venv/bin/python scripts/verify_phase7.py --output-dir runtime/phase7-acceptance
ALGOFACTORY_DOCKER_TESTS=1 .venv/bin/python -m pytest -q
```

验收包含真实容器执行及表单提交，耗时取决于本机环境；不调用付费 API。它只验证训练和验证集流程，不新增最终测试。

## 常见情况

- **升级后页面仍报旧错误**：停止并重新启动工作台服务，仅刷新浏览器不足以重载所有 Python 模块；已有任务与报告保留。
- **镜像未准备或过期**：按 README 重建批准镜像。worker 变化后旧镜像不能继续用。
- **模型缺失或环境不匹配**：到“试用算法”显式准备或重新准备该版本。旧产物保留，系统不会静默换版本。
- **输入被拒绝**：输入非空、1–1000 字符的英文咨询，不要复制冻结测试集文本。原型只支持已知意图，没有未知类别识别能力。
- **请求预算耗尽**：查看已保留证据，再手动决定是否提交新任务。系统不会自动扩额。
- **验证未通过**：不把此模型当作合格试用版本；查看具体失败维度和修复记录。

真实 API 模式仍会产生费用。此次 Phase 7 新增功能用 Mock 验证真实执行，未新增付费接口实验。工作台是本机服务，GitHub 私有仓库不等于公网网页部署。
